How it works →

Everything a messages app needs, nothing that reads it

One-time password detection runs locally with a keyword and digit-pattern check. No message is ever analysed on a server.

Conversation list

Every thread with the contact name, initials, last message and a timestamp.

Smart categories

All, Personal, OTP and Others as one-tap filters above the list.

OTP detection

Messages carrying a one-time code are recognised on the device and grouped together.

Real search

Match a name, a number or a phrase inside the message body.

Compose and reply

Message bubbles with a reply box, plus a full composer for a new number.

Link handling

Opens sms: and smsto: links from browsers, and splits long messages into parts.

Default-SMS ready

All four components Android requires — SMS_DELIVER, WAP_PUSH_DELIVER, RESPOND_VIA_MESSAGE and SENDTO.

Contact names

Numbers are matched to your contacts so threads read as people, not digits.

Appearance

Theme and accent colour, shared with the rest of the Nijatva suite.

Install

Sideload the signed APK. It updates over older Nijatva Messages builds signed with the same key.

1 — Download

Grab the latest APK from the releases page.

2 — Allow install

When Android asks, allow your browser or file manager to install unknown apps.

3 — Grant SMS

Android will ask for SMS access; without it there is nothing to show.

Prefer a cable? One command:

adb install -r Nijatva_Messages_v1.1.apk

Privacy is a permission, not a promise

The manifest does not request android.permission.INTERNET, so no message, number or contact can be uploaded by this app.
